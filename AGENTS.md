# Self-correcting rules

At the start of each session, read the entire Learned rules section before beginning task work.

Immediately append a rule when the user explicitly corrects an output, rejects a file approach or pattern, states a preference, or when a mistake or bug results from a wrong assumption. Continue the numbering sequentially. Write each rule as a clear imperative using the format `N. [Category] Always or never do X because Y`.

## Learned rules

1. [Aktualizacja strony] Zawsze sprawdzaj nowe i zmienione materiały projektu podczas aktualizacji strony Kulpilates i uwzględniaj informacje przeznaczone dla odwiedzających, ponieważ treść strony ma odzwierciedlać aktualne materiały studia.

2. [Wygląd strony] Zawsze używaj ilustracji marki w sekcji otwierającej stronę Kulpilates, ponieważ użytkownik woli ją od zdjęcia.

3. [Wygląd strony] Zawsze wyświetlaj ilustrację w sekcji otwierającej stronę Kulpilates w poziomym odbiciu lustrzanym, ponieważ użytkownik wybrał tę orientację.

4. [Wygląd strony] Zawsze dopasowuj kolor ilustracji i jej tło w sekcji otwierającej do niebieskiego logo i kremowego tła po lewej, ponieważ użytkownik chce spójnej kolorystyki obu części.
